# Demo runbook (offline/local fixtures)

**Target:** 60–90 seconds. **Mode:** local demo passphrase, three explicitly labelled fixtures. This runbook does not represent live Twitch authorization or live acceptance.

1. Start with the Review Desk and say: “This is a narrow research aid, not an AI truth oracle. Nothing appears on stream until the broadcaster approves it.”
2. Click **Try the demo**. Point out that the Pluto definition and AU/light-year questions have two and one retrieved source records respectively; the Saturn moon-count prompt is deliberately a valid **not enough evidence** result, not a failed request.
3. Select the Pluto question. Read the NASA/JPL excerpts and check date before the deterministic draft. State plainly: “No model is used; these templates are local.”
4. Select one or two sources, edit the public title/summary/caveat if needed, inspect the exact 16:9 overlay preview, check the confirmation, and approve.
5. Open the read-only overlay. Show the source labels/links and uncertainty line. Return to Published & recap and download the Markdown export, which omits the original question and viewer identity.
6. End with Setup: this run is demo-only; no Twitch account, chat message, or moderator role was tested.

**Safety fallback:** If no suitable evidence is visible, choose **Insufficient evidence**; never improvise a fact. If local services fail, state “No card was published” and use the preloaded demo path only after restarting. Do not show a real viewer name, token, or private chat message.
