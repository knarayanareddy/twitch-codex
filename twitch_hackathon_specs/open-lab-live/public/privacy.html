TRANSPARENCY NOTE

What the model
does not know.

Scientific limits

The selected source supports the qualitative idea that albedo is reflectivity and that less-reflective surfaces absorb a larger share of incoming light. Open Lab Live runs a tiny arithmetic rule using illustrative 20%, 50%, and 80% settings. It does not estimate temperature, melting, local weather, ecological effects, or climate outcomes. The figures are not measurements.

What is stored

  • Lesson/session version, random replay seed, phase transitions, timestamps, and each completed aggregate run.
  • To prevent repeat votes, a per-session keyed hash of the input identity and the current cycle/choice/source are kept until session expiry. Raw chat text and viewer display names are not stored.
  • Operator passphrase is held in the server environment. Operator cookie is signed, HttpOnly, and expires after eight hours.

Retention and export

Session records, vote-dedupe rows, seeds, and event summaries are pruned after 24 hours. Markdown and JSON exports include aggregate counts, selected model condition, output, assumptions, source, lesson version, and replay seed. Do not share them as real scientific findings.

Identity and integration

This build does not connect to Twitch. The simulator’s sample voters are fixtures, not Twitch users. No external model provider is used. When Twitch integration is added, the source adapter must pass only a normalized choice, stable actor ID, and provider delivery ID—not raw chat text.

Accessibility note

Controls and results are presented as text with keyboard focus and reduced-motion support. Automated axe checks are quality checks, not WCAG certification. Manual screen-reader and real-user reviews are still required before claiming conformance.
